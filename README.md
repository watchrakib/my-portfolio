## GitHub Pages
1. Create a GitHub repository.
2. Upload every file and folder from this package.
3. Keep `index.html` in the repository root.
4. Go to **Settings → Pages**.
5. Choose **Deploy from a branch**, your main branch, and `/(root)`.
6. Save and wait for publishing.

Before publishing, replace `your-email@example.com` in `index.html` with your real email.
